# Animated-pfp-Serialized
1 - open [Serializd](https://www.serializd.com) settings, inspect element the upload button, then go to Application → Cookies → click on "tvproject_credentials" and copy the value that looks like random gibberish (DO NOT share it with anyone)

2 - copy your image/gif file path

3 - paste your token instead of `[YOUR_TOKEN_HERE]`

4 - paste your image path instead of `[IMAGE_PATH_HERE]` and remove the brackets

5 - put the whole command in CMD and boom, your pfp should upload
